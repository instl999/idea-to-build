# Team Brief Generator - Constraints

## Immutable

- Local-only processing.
- Explicit source traceability.
- No accounts or autonomous task assignment.
- No compliance claims.

## Delivery

- Two TypeScript developers and one designer.
- Four-week MVP.
- Open-source dependencies and no mandatory per-document service cost.

## Operational

- One active document, maximum input 200 KB, maximum 500 stored briefs.
- Updates preserve saved briefs; backup and restore are documented.
- Telemetry is off by default and logs contain no meeting text.

## Reversible defaults

- English-only UI and notes for MVP.
- Deterministic rules before any optional on-device model investigation.
