# Task Specifications

Each development task owns one directory containing `SPEC.md` and `PLAN.md`. The task ledger is canonical for identity and status; the SPEC is canonical for accepted scope and observable acceptance; the PLAN tracks execution progress and recovery.

A task cannot become `ready` without a concrete acceptance criterion, cannot become `in_progress` without SPEC/PLAN, and cannot become `done` without current-snapshot quality evidence and required human acceptance.
