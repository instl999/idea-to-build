# Generated design set

After requirements readiness and core freeze, generation produces product requirements, user stories, user flows, feature and non-functional requirements, data model, API contract, system context, components, module boundaries, dependencies, security/privacy/permissions, error handling, observability, testing, deployment, rollback, MVP roadmap, risks, reuse matrix, and Codex orchestration artifacts in this directory.

`MCP_INTEGRATION_GUIDE.md` records one post-readiness recommendation: not applicable, use a verified existing server, build a justified custom server, or defer for missing evidence. It is not permission to install software, execute copied setup commands, or write credentials automatically.

Every section labels user-confirmed facts, AI recommendations, reversible defaults, unverified assumptions, and immutable constraints.
